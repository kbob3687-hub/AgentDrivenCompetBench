## 冒烟实测校准（2026-11-05，notion-stress-001 × 3 臂）

三臂在同一冻结包上实测（QA 臂/无 QA 臂在同一代码状态，基线臂晚 10 分钟、多了 JSON 解析重试保险）：

| 臂 | 实测 token | 实测时延 | LLM 调用 | 纸面估算 token | 偏差 |
|---|---:|---:|---:|---:|---|
| 多 Agent 带 QA | 117,200 | 248.5s | 7 | 99,487 | +18% |
| 多 Agent 无 QA | 52,575 | 113.9s | 3 | 87,549 | -40% |
| 单次 LLM 基线 | 17,893 | 69.2s | 1 | 24,511 | -27% |

- 上表多 Agent 无 QA 一行为估算表的 0.88 折算值；实测 QA/无 QA token 比为 **0.45**（该 case QA 跑满两轮、7 次调用）。历史 20 任务全量对照是 0.88（多数任务 QA 一轮就过）。无 QA 臂的真实区间取 **0.45–0.88**，正式报告以实测为准。
- 基线臂首跑（20261105T121544Z-4a4ceb72）因模型输出 JSON 在第 3525 字符处非法而失败，已加一次重试保险后重跑成功（20261105T122126Z-b4415c9c，首轮即过）。失败 run 按纪律保留在 results 目录。
- 冒烟总花费：有效 3 run ≈ 187,700 token + 作废尝试 ≈ 21,600 token。
- **注意：三次冒烟的源码指纹不完全一致**（基线臂修复后重跑）。正式实验必须先提交冻结 commit，三臂在同一 commit 下运行。
